🖥️ Giao diện Modal JSON

Modal mới có 3 tabs chính:

1. Tab "JSON Data" 📝

  • Hiển thị dữ liệu JSON raw trong textarea
  • Font Courier New, readonly, có scroll
  • Background màu xám nhạt

2. Tab "Preview" 👁️

  • Bên trái: Thông tin header (khách hàng, ngày, mẫu số, v.v.)
  • Bên phải: Chi tiết sản phẩm dạng bảng
  • Hiển thị dữ liệu được format đẹp

3. Tab "Thông tin" ℹ️

  • Kích thước file JSON
  • Số lượng sản phẩm
  • Thời gian tạo
  • Trạng thái hóa đơn
  • Tổng tiền

🔍 Troubleshooting

Vấn đề Nguyên nhân Giải pháp
Nút "Xem JSON" không hiện Chưa load modal hoặc lỗi JS F12 kiểm tra console, reload trang
"Không tìm thấy hóa đơn điện tử" Chưa lưu HD điện tử cho đơn hàng Click "Lưu HĐ điện tử" trước
Modal không mở Conflict JS hoặc Bootstrap Kiểm tra jQuery và Bootstrap
JSON không hiển thị Lỗi AJAX hoặc controller Kiểm tra Network tab trong F12
